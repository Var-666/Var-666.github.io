# VAR · 日常工具箱

浏览器本地处理的日常工具箱：文本整理、图片与文件格式转换。

[在线使用](https://www.hi-var.top/)

React + TypeScript + Vite + Tailwind CSS 4，使用官方 shadcn/ui New York 组件、Radix UI、Lucide 图标和 Sonner 通知。

## 本地运行

```sh
npm install
npm run dev
```

打开终端打印的本地地址。`npm run format` 统一格式，`npm run format:check` 检查源码排版；发布流程会运行格式检查。`npm test` 验证整理规则，`npm run build` 完成 TypeScript 检查并生成 `dist/`，`npm run preview` 查看构建结果。

## 工具与入口

- `#/`：工具箱首页。
- `#/text`：文本整理，保留现有全部功能。
- `#/pdf`：PDF 页面整理。
- `#/rename`：批量重命名。
- `#/files`：文件格式转换。使用 hash 路由，GitHub Pages 刷新子页面无需重写规则。
- 工具之间切换会保留当前页面内的输入和转换结果；刷新或关闭后清空。主题在首页与各工具间共用。没有手动设置时跟随系统深浅色，手动切换后保存偏好，并同步浏览器主题色。首页只加载导航外壳，文本工具和文件工具均按需加载。

## 文件格式转换

- PNG / JPG / WebP 互转，最多 10 个文件，可在空闲时追加、逐项移除、单独下载或 ZIP 打包，追加后的总量仍受限制。支持直接粘贴截图，按原尺寸、最大宽度 1920 / 1280 或 50% 缩放，不放大小图。单张 20 MB、2400 万像素，总输入 50 MB、总输出 100 MB。JPG 透明背景填白，动画仅保留第一帧，元数据不保留。
- 多张图片 → PDF：支持拖动与箭头排序，每张图片一页 A4、居中留白，透明区域填白；按 144 DPI 上限缩放并使用 JPG 编码，不是无损图片归档。修改队列后旧结果失效，需重新合并。
- PDF → PNG / JPG：144 DPI，支持页码与范围（如 `1,3-5`，按原文顺序、重复页去重），支持文字与扫描页面。单页直接下载，多页 ZIP；也可拼成长图（最大 2400 万像素、高度 16384 px），加密 PDF 拒绝转换。
- Markdown → TXT，复用现有 Markdown 解析规则。
- CSV / TSV / Excel 复制内容 → Markdown 表格：首行为表头，保留前导零，转义格式字符与竖线，多行单元格使用 `<br>`。不读取 `.xlsx` 文件。
- Markdown 表格 → CSV：提取所有标准 Markdown 表格（包括引用或列表里的表格，跳过代码块）；多张表格 ZIP 导出，内联格式转纯文本，疑似公式添加单引号。
- CSV → JSON：逗号分隔、首行为唯一且非空的列名；保留字符串和前导零，支持引号、逗号、换行。
- JSON → CSV：非空对象数组，不支持嵌套字段；合并所有列，缺失字段留空，长整数需要写成字符串；对疑似表格公式添加单引号。
- Word `.docx` → PDF：浏览器渲染并输出图片版 A4 PDF，文字不能选择。切页优先在边界前 80 像素内寻找连续空白行；无空白的图像和表格边框仍回退固定切页。字体、复杂分页、表格等不保证原样还原，不支持旧 `.doc`。外部资源在隔离渲染区域内禁止加载，文件解压大小受限。
- 文字型 PDF → Word `.docx`：提取文字、保留页间分页，不恢复图片、表格与布局。扫描件、含无文字页的混合文档、加密 PDF 不转换，以免无提示地遗漏内容。
- 文本类文件单个 2 MB、UTF-8；办公文档单个 10 MB、最多 50 页。所有转换在本地执行，没有服务端或文件上传。转换依赖按需加载。`predev` / `prebuild` 从已安装的 PDF.js 复制中文字符映射与标准字体到 `public/pdf-assets/`，该生成目录不提交 Git。

## PDF 页面整理

- 多个 PDF 合并，勾选或输入当前顺序页码提取，删除单页或所选页，旋转和拖动 / 箭头排序；导出新 PDF，保留页面图文与原始尺寸，不将页面转为图片。
- 最多 10 个文件、单个 20 MB、总输入 50 MB，原文合计最多 100 页，输出最大 100 MB。删除某来源的所有页面后释放该来源，修改操作会让旧结果失效。
- 加密、带表单（包含孤立 Widget）、XFA 或数字签名权限的文件拒绝整理，避免破坏表单或签名。书签不保留，内部跳转、附件及特殊文档结构未承诺保留。
- PDF.js 缩略图按可见区域渲染，点击可打开整页预览，支持缩放（最大 400%，超大页面受尺寸限制）、适合页面与按当前列表顺序翻页；桌面初始 100%，窄屏初始适合页面。Esc 关闭后回到原缩略图，切换工具自动关闭预览。pdf-lib 按需加载；无需上传。浏览器内存保留草稿，刷新清空。

## 批量重命名

- 支持任意文件格式、追加和逐项移除 / 调序；统一名称、区分大小写的文字替换（全部匹配）、前后缀、起始编号及 1–4 位最小补零宽度。保留最后一个扩展名，点文件作为无扩展名处理。
- 实时预览每个文件的新旧名称；拦截重名（包括大小写与 Unicode 标准化后的冲突）、非法字符、常见系统保留名、超长名称和无效编号。ZIP 库不支持的扩展名为空的 `__proto__` 名称也会被提示调整。
- 最多 100 个文件、总计 100 MB；允许空文件。仅在本地生成 ZIP 副本，解压后的文件内容与原文件相同；不会修改磁盘上的原文件，也不读取文件内容作分析。规则或队列变化后旧 ZIP 失效。

## 文本整理

- 日常清理、PDF 复制文字断行修复、名单去重、中文排版、Markdown 转纯文本。
- Markdown 模式去除标题、强调、引用和列表标记，保留代码内容和缩进；链接保留为“文字（网址）”，图片保留说明，表格转成制表符分隔的文本行。
- 原文与结果对照，实时整理，单项规则设置，恢复预设。
- TXT / Markdown 导入及拖放（UTF-8，最大 2 MB、100 万字符），TXT 下载，复制结果。
- 撤销上次导入、示例替换或清空。原文框输入支持浏览器原生撤销。
- 手机端原文/结果切换，深浅主题，键盘操作，使用指南。
- 文本通过 Web Worker 在本地处理；只把设置和主题保存在 localStorage，正文不自动持久化。

## 结构

- `src/App.tsx`：首页、导航和共用主题。
- `src/TextTool.tsx`：原文本工具、文件与剪贴板交互、设置。
- `src/PdfTool.tsx` / `src/lib/pdf-organize.ts`：PDF 页面预览、编排与矢量页面复制。
- `src/RenameTool.tsx` / `src/lib/rename.ts`：重命名规则、冲突检查与文件包。
- `src/FileTool.tsx`：转换队列、错误状态、结果与批量下载。
- `src/lib/file-convert.ts`：本地图片与办公文档转换。
- `src/lib/file-media.ts`：PDF 图片导出、图片合并 PDF 与 ZIP 打包。
- `src/lib/media-options.ts`：图片缩放与 PDF 页码校验。
- `src/lib/file-text.ts`：CSV / JSON 与 Markdown 文件转换。
- `src/lib/text.ts`：纯函数整理规则、场景预设、统计。
- `src/lib/markdown.ts`：基于 Marked 语法分析的纯文本转换，不渲染或执行 HTML。
- `src/lib/markdown.test.ts`：Markdown 格式、代码、链接、图片、表格等转换测试。
- `src/lib/text.worker.ts`：后台整理线程。
- `src/lib/text.test.ts`：保护段落、列表、链接、数字和去重顺序的测试。
- `src/lib/clipboard.test.ts`：剪贴板成功、权限拒绝及超时的测试。
- `src/components/ui/`：来自官方 shadcn/ui 注册表的组件。
- `src/index.css`：设计变量、布局及手机适配。

## 部署与边界

线上地址：https://www.hi-var.top/ 。推送到 `main` 后，GitHub Actions 使用 Node.js 22 安装锁定依赖、运行测试、构建并发布 `dist/` 到 GitHub Pages。自定义域名沿用仓库 Pages 设置，本地电脑无需保持开机。回退到此前的 Git 提交并重新发布即可恢复旧版。

`dist/` 是标准静态网站产物，可以部署在支持 HTTPS 的静态托管或自己的服务器上，再配置域名。剪贴板接口需要 HTTPS 或 localhost，权限不足时会提示使用键盘复制粘贴。

Markdown 默认保留空格与空行，避免破坏代码缩进；另外开启清理或排版规则时，这些规则会继续作用于转换后的纯文本。任务列表的复选框作为格式标记去除，正文保留。

文本整理中的 PDF 断行修复接受复制后的纯文本；PDF 文件转换在文件工具中使用。断行修复为启发式规则，复杂表格、多栏与特殊编号可能需要手动调整。操作统计按规则命中次数计算，不等同于修改字符总数。刷新会清空正文，下载结果前请检查预览。
