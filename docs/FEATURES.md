# 功能与限制 · 详细说明

README 是产品介绍；这里按工具列出完整的能力边界、文件大小与数量限制，以及面向开发者的结构说明。各轮验证记录见 [CHECKS.md](../CHECKS.md)。

## 工具与入口

- `#/`：工具箱首页。支持按名称、功能与常见任务关键词搜索（多个关键词空格分隔、须全部命中）；「常见任务」入口直达具体转换方式（如 `#/files?mode=image-compress`）；工具卡片可收藏（星标），「常用工具」与「最近使用」区块在刷新后保留。收藏与最近使用只保存工具 id 与时间戳，不保存任何正文或文件内容。
- `#/text`：文本整理。
- `#/pdf`：PDF 页面整理。
- `#/rename`：批量重命名。
- `#/compare`：表格对比。
- `#/table`：表格批量处理。
- `#/files`：文件格式转换。使用 hash 路由，GitHub Pages 刷新子页面无需重写规则。
- 工具之间切换会保留当前页面内的输入和转换结果；刷新或关闭后清空。主题在首页与各工具间共用。没有手动设置时跟随系统深浅色，手动切换后保存偏好，并同步浏览器主题色。首页只加载导航外壳，各工具均按需加载。

## 界面与可访问性

- 首页任务入口、工具卡片、自定义预设使用统一字号层级；收藏与跳转图标分开。651–1100px 下导航独立一行，手机保留主题按钮。
- 文本编辑器与差异高亮层共享字体、行高、内边距与换行规则，覆盖 650/900px 断点；设置弹窗将规则与自定义预设放进同一滚动区，底部按钮保持可达。
- 常用输入框统一高度与键盘焦点环，CSV/Excel 数据矩阵共享表头、12px 字号与等宽数字；390px 界面及导入后的预览均验证无横向溢出。

## 文件格式转换

- PNG / JPG / WebP 互转，最多 10 个文件，可在空闲时追加、逐项移除、单独下载或 ZIP 打包，追加后的总量仍受限制。支持直接粘贴截图，按原尺寸、最大宽度 1920 / 1280 或 50% 缩放，不放大小图。单张 20 MB、2400 万像素，总输入 50 MB、总输出 100 MB。JPG 透明背景填白，动画仅保留第一帧，元数据不保留。
- 图片压缩：指定目标大小（100 KB / 200 KB / 500 KB / 1 MB），输出 JPG 或 WebP，可设尺寸上限（等比缩放）；转换参数（输出格式、尺寸、质量、压缩目标、PDF 合并参数、页码、数字识别开关等）会记忆在本地，下次打开自动恢复，可在浏览器设置中清除。优先降低编码质量，仍超限再逐级缩小尺寸（最低到原图 25%）；无法达标时如实显示实际大小并说明，不假装成功。每个文件显示「原始大小 → 输出大小 · 尺寸 · 质量」对比，批量支持单独下载或 ZIP 打包；JPG 透明背景填白。
- 多张图片 → PDF：支持拖动与箭头排序，每张图片一页；页面尺寸可选 A4 / A3 / Letter，方向纵向或横向，适配方式可选完整显示（四周留白）或填满页面（超出部分位于页面外不可见）；透明区域填白，按 144 DPI 上限缩放并使用 JPG 编码，不是无损图片归档。修改队列或设置后旧结果失效，需重新合并。
- PDF → PNG / JPG：144 DPI，支持页码与范围（如 `1,3-5`，按原文顺序、重复页去重），支持文字与扫描页面。单页直接下载，多页 ZIP；也可拼成长图（最大 2400 万像素、高度 16384 px），加密 PDF 拒绝转换。
- Markdown → TXT，复用现有 Markdown 解析规则。
- CSV / TSV / Excel 复制内容 → Markdown 表格：首行为表头，保留前导零，转义格式字符与竖线，多行单元格使用 `<br>`。不读取 `.xlsx` 文件。
- Markdown 表格 → CSV：提取所有标准 Markdown 表格（包括引用或列表里的表格，跳过代码块）；多张表格 ZIP 导出，内联格式转纯文本，疑似公式添加单引号。
- CSV → JSON：首行列名与 Excel → JSON 同规则（空表头按「列N」、重复表头加序号后缀并提示）；保留字符串和前导零，支持引号、逗号、换行。
- Excel（.xlsx）→ CSV / JSON / Markdown：SheetJS（按需加载）读取真实工作簿，可切换工作表并预览前 20 行；单元格一律按 Excel 显示值导出——文本原样保留，`000000` 等数字格式渲染的前导零、日期时间显示形式随格式保留，公式取源文件缓存结果（无缓存时按空值并在预览中提示）。JSON 的空表头按「列N」、重复表头加序号后缀并提示；超过 15 位有效数字的数值会提示可能已丢失精度。一次处理一个工作簿（10 MB、单表 10 万行 × 1024 列、100 万格以内；解压总量上限 256 MB）。不保留样式、条件格式、合并单元格、图表与宏。
- CSV → Excel（.xlsx）：默认全部按文本写入，保留前导零与长编号，不会把字符串写成公式；可开启「尝试识别数字」，仅转换无前导零、非科学计数的普通数字。输出可被 Excel / WPS 正常打开，文件名如 `订单.csv → 订单.xlsx`。
- JSON → CSV：非空对象数组，不支持嵌套字段；合并所有列，缺失字段留空，长整数需要写成字符串；对疑似表格公式添加单引号。
- Word `.docx` → PDF：浏览器渲染并输出图片版 A4 PDF，文字不能选择。切页优先在边界前 80 像素内寻找连续空白行；无空白的图像和表格边框仍回退固定切页。字体、复杂分页、表格等不保证原样还原，不支持旧 `.doc`。外部资源在隔离渲染区域内禁止加载，文件解压大小受限。转换后可在「结果详情」中查看页数、文件大小、文档分节数、质量提示与逐页 PDF 预览（与下载文件同源）；单个分节渲染失败会计数提示而不会静默丢页。
- 文字型 PDF → Word `.docx`：提取文字、保留页间分页，不恢复图片、表格与布局。扫描件、含无文字页的混合文档、加密 PDF 不转换，以免无提示地遗漏内容。转换后「结果详情」显示提取字符数、段落数、页数与实际写入 Word 的文本预览，并提示核对关键内容。
- 文本类文件单个 2 MB、UTF-8；办公文档单个 10 MB、最多 50 页。所有转换在本地执行，没有服务端或文件上传。转换依赖按需加载。`predev` / `prebuild` 从已安装的 PDF.js 复制中文字符映射与标准字体到 `public/pdf-assets/`，该生成目录不提交 Git。

## 表格对比（#/compare）

- 导入两份 CSV 或 .xlsx（旧表 / 新表，XLSX 可选工作表），选择主键列按主键匹配：列出新增、删除与修改记录，修改逐列显示旧值 → 新值；可勾选参与比较的列、可选空格规范化（仅空白不同视为相同，明细仍显示原值）。
- 重复主键按首次出现参与匹配并显式提示（不静默合并），主键为空的行不参与匹配并计数，只有一侧存在的列会作为结构差异列出；不自动猜测主键，缺失值不等于零值。
- 差异可导出 XLSX（新增 / 删除 / 修改明细三个工作表）或 CSV ZIP；比较按单元格显示文本进行，不比较公式与样式。

## 表格批量处理（#/table）

- 导入多份同结构 CSV（表头必须完全一致，否则点名文件拒绝），按固定顺序处理：合并 → 按关键列去重（保留第一条 / 最后一条）→ 按列筛选（包含 / 不包含）→ 删除指定列 → 按字段值拆分（空值归入「（空值）」组，组名做非法字符清理）。
- 每一步的影响（去重删除、筛选移除、删列、分组数）在预览统计中给出，结果预览前 10 行；导出 CSV（拆分为 ZIP）或 XLSX（拆分为多工作表）。单个文件失败不影响其他文件。
- 限制：单个 CSV 2 MB、UTF-8，最多 10 份、合计 10 万行 / 100 万格；只处理普通表格数据，不支持公式、样式与合并单元格。

## PDF 页面整理

- 多个 PDF 合并，勾选或输入当前顺序页码提取，删除单页或所选页，旋转和拖动 / 箭头排序；导出新 PDF，保留页面图文与原始尺寸，不将页面转为图片。
- 拆分导出：把当前所选页按「每页一个文件 / 每 N 页一个文件 / 自定义页码段（如 1-3,4-6，每页恰属一段、顺序按输入保留）」拆成多份 PDF 打包 ZIP；每份输出用 pdf-lib 重新打开验证可读，验证失败仅提示不阻止下载。页码段不覆盖全部所选页、或每 N 页不小于总页数时会明确拒绝。
- 最多 10 个文件、单个 20 MB、总输入 50 MB，原文合计最多 100 页，输出最大 100 MB。删除某来源的所有页面后释放该来源，修改操作会让旧结果失效。
- 加密、带表单（包含孤立 Widget）、XFA 或数字签名权限的文件拒绝整理，避免破坏表单或签名。书签不保留，内部跳转、附件及特殊文档结构未承诺保留。
- PDF.js 缩略图按可见区域渲染，点击可打开整页预览，支持缩放（最大 400%，超大页面受尺寸限制）、适合页面与按当前列表顺序翻页；桌面初始 100%，窄屏初始适合页面。Esc 关闭后回到原缩略图，切换工具自动关闭预览。pdf-lib 按需加载；无需上传。浏览器内存保留草稿，刷新清空。

## 批量重命名

- 支持任意文件格式、追加和逐项移除 / 调序；统一名称、区分大小写的文字替换（全部匹配）、前后缀、起始编号及 1–4 位最小补零宽度。保留最后一个扩展名，点文件作为无扩展名处理。
- 实时预览并逐项编辑：新文件名单元格可直接修改（覆盖名走同一套校验，还原按钮回到生成名）；可从文本列表导入目标名称（每行一个，数量不一致明确报错），导入后仍可继续微调。
- 生成名称可选清理：特殊字符替换为空格、折叠空格、合并重复分隔符（只作用于主名，扩展名不变）。
- 拦截重名（包括大小写与 Unicode 标准化后的冲突，覆盖名与生成名一并参与检测）、非法字符、常见系统保留名、超长名称和无效编号。
- 最多 100 个文件、总计 100 MB；允许空文件。仅在本地生成 ZIP 副本，解压后的文件内容与原文件相同；不会修改磁盘上的原文件，也不读取文件内容作分析。规则或队列变化后旧 ZIP 失效。

## 文本整理

- 日常清理、PDF 复制文字断行修复、名单去重、中文排版、Markdown 转纯文本。
- 自定义预设：在「全部设置」里把当前场景与规则组合保存为命名预设（最多 12 个，同名覆盖），预设卡片下方一键应用，也可在设置里应用或删除；预设只保存规则，不保存任何正文。
- 「更多操作」独立面板（默认收起）：批量查找替换（多条规则按顺序执行、逐条命中计数、区分大小写与正则开关、预览后应用并可重复执行）；列表处理（拼音 / 长度排序、包含 / 排除筛选、行号、行前后缀、删空行，显示行数变化、不去重）；格式转换（多行 ↔ 逗号 / 分号 / 制表符，带引号列表与 SQL `IN (…)`，单行自动按分隔符拆分，空条目计数后丢弃）；批量文件处理（一次导入最多 20 份 TXT / MD，统一应用主编辑器当前的整理规则，逐文件显示前后大小与调整处数、可展开预览，单个文件的错误（过大 / 非 UTF-8）只标记该文件不影响其他，逐个下载或打包 ZIP）。应用写回原文并进入撤销栈，规则保留可重复执行。
- PDF 断行修复提供「保守 / 标准」两种模式：保守只合并有较强续行证据的断行（句末标点、结构标记处一律保留），标准在结构保护下更积极合并软换行；支持标题、章节号、编号与项目列表、表格行、围栏与行内代码、URL / 邮箱、小数日期版本号与英文跨行连字符识别，复合词断行时保留连字符。断行修复为启发式规则，复杂表格、多栏与特殊编号可能需要手动调整；标准模式可能把无空行分隔的两个段落并为一段，重要文档建议先用保守模式。
- 「保留换行」按钮在光标所在行尾插入 ⟦保留换行⟧ 标记：该处换行在任何模式下都不会被合并，结果中自动移除标记；标记是一次性编辑辅助，再次处理输出文本时原先受保护的换行会被正常判断。
- Markdown 模式去除标题、强调、引用和列表标记，保留代码内容和缩进；链接保留为“文字（网址）”，图片保留说明，表格转成制表符分隔的文本行。
- 整理前后差异高亮：原文一侧标出被删除的字符，结果一侧标出新增的字符；「修改明细」逐条列出新增 / 删除 / 替换，点击即滚动定位。正文与结果合计 20 万字符以内可用，超出或碎块过多时自动停用高亮，不影响整理本身。操作统计按规则命中次数计算，不等同于修改字符总数。
- TXT / Markdown 导入及拖放（UTF-8，最大 2 MB、100 万字符），TXT 下载，复制结果；撤销上次导入、示例替换或清空。手机端原文 / 结果切换，深浅主题，键盘操作，使用指南。
- 文本通过 Web Worker 在本地处理；只把设置、预设和主题保存在 localStorage，正文不自动持久化。

## 部署与边界

线上地址：https://www.hi-var.top/ 。推送到 `main` 后，GitHub Actions 使用 Node.js 22 安装锁定依赖、运行格式检查、lint、单元测试、Playwright 端到端回归，全部通过后构建并发布 `dist/` 到 GitHub Pages。自定义域名沿用仓库 Pages 设置。回退到此前的 Git 提交并重新发布即可恢复旧版。

`dist/` 是标准静态网站产物，可以部署在支持 HTTPS 的静态托管或自己的服务器上。剪贴板接口需要 HTTPS 或 localhost，权限不足时会提示使用键盘复制粘贴。

离线与安装：生产构建注册 Service Worker。`postbuild` 根据构建内容生成版本及完整预缓存清单（含懒加载工具、转换依赖和 PDF 中文字体），安装先缓存核心入口，页面空闲时补齐全部资源；顶栏显示进度、失败重试与「离线就绪」。首次准备需约 7.5 MB 本地缓存，完成后未访问过的工具也能断网使用。缓存写入失败不会妨碍在线操作。可安装到桌面 / 主屏幕（`manifest.webmanifest`），开发模式不注册。

- 导航请求网络优先，仅成功 HTML 能更新离线入口；带哈希资源与本地 PDF 资源命中缓存直接返回，其他静态资源后台更新。新 SW 激活只清理本站旧版本缓存，保留其他应用缓存。构建时同步生成 sitemap 的 lastmod。
- 每个工具独立处理加载失败，显示重试、刷新与返回首页；重试不清空其他工具草稿。旧分块失效时，仅在用户尚未操作且在线的情况下最多自动刷新一次；已有操作时保留当前页面，让用户自行决定何时刷新。刷新/关闭仍会清空当前文件和正文。
- SheetJS 0.20.3 官方原始 tarball 保存在 vendor/，SHA-512 与既有 lockfile 一致；npm 安装无需请求 SheetJS CDN。来源与许可证见 THIRD_PARTY_NOTICES。

SEO 与安全：`robots.txt` 与 `sitemap.xml` 随构建发布；页面带 canonical、Open Graph、Twitter 卡片与 JSON-LD 描述。因为使用 hash 路由且 GitHub Pages 对路径路由返回 404 状态，各工具页不单独进站点地图，搜索引擎只收录首页。`index.html` 内置 CSP，脚本仅允许同源且不含 `unsafe-eval`。

## 代码结构

- `src/App.tsx`：首页（搜索、收藏、最近使用、任务入口）、导航和共用主题。
- `src/TextTool.tsx` + `src/text-tool/TextBatchOps.tsx`：文本工作台与批量操作面板。
- `src/FileTool.tsx` + `src/file-tool/`：转换队列、模式元数据、文件队列、结果详情与 Excel / CSV 预览。
- `src/CompareTool.tsx` + `src/lib/table-compare.ts`：表格差异对比。
- `src/TableTool.tsx` + `src/lib/table-process.ts`：表格批量处理管道。
- `src/PdfTool.tsx` + `src/lib/pdf-organize.ts`：PDF 页面预览、编排、拆分与矢量页面复制。
- `src/RenameTool.tsx` + `src/lib/rename.ts`：重命名规则、覆盖、冲突检查与文件包。
- `src/lib/file-convert.ts`：图片转换、openPdf、Word / PDF 互转。
- `src/lib/file-media.ts`：PDF 图片导出、图片合并 PDF、ZIP 打包。
- `src/lib/image-compress.ts`：压缩到目标大小的搜索策略与浏览器编码。
- `src/lib/file-text.ts` / `src/lib/text-ops.ts` / `src/lib/text-batch.ts`：CSV / JSON / Markdown 转换、批量文本操作与批量文件处理。
- `src/lib/file-excel.ts`：Excel 工作簿读取（显示值保真、zip 预检查、集中上限）与 XLSX 生成。
- `src/lib/convert-report.ts`：Word / PDF 互转的结果校验与质量报告。
- `src/lib/text.ts` / `src/lib/text-diff.ts` / `src/lib/text.worker.ts`：纯函数整理规则、差异计算与后台线程。
- `src/lib/storage.ts`：本地存储（主题、设置、预设、收藏、最近使用、参数记忆），旧键迁移。
- `src/lib/home-search.ts`：首页搜索与任务入口索引。
- `e2e/`：Playwright 端到端回归（文件转换、首页、文本、对比、批处理、PDF、重命名、离线、移动端）。

shadcn/ui 组件按 MIT 许可分发，见 `THIRD_PARTY_NOTICES.md`。
